# Personal website 

A small, accessible, responsive personal site for hosting Astrophotography images, and personal projects.

## Files

- `index.html` : landing page with one large image and links to astrophotography & project sections.
- `astrophotography.html` : astrophotography gallery.
- `projects.html` : personal project gallery.
- `styles.css` — responsive styles.
- `gallery.js` — JavaScript file supporting the photo gallery.
- `media/` — original photographs to be used by the live site, held from git.
